# USVI Reporting SPFx Concept Mockup

This folder contains a standalone interactive demonstration of the proposed weekly and monthly reporting forms.

## Publish with GitHub Pages

1. In GitHub, create a new repository such as `usvi-reporting-mockup`.
2. Upload `index.html` and `.nojekyll` to the root of the repository.
3. Commit the files to the `main` branch.
4. Open **Settings** in the repository.
5. Select **Pages** under **Code and automation**.
6. Under **Build and deployment**, select **Deploy from a branch**.
7. Select the `main` branch and the `/(root)` folder, then select **Save**.
8. Wait for GitHub to publish the site. The Pages screen will display the shareable URL.

For a repository named `usvi-reporting-mockup`, the typical address is:

`https://YOUR-GITHUB-USERNAME.github.io/usvi-reporting-mockup/`

## Important sharing note

Treat a GitHub Pages site as publicly accessible unless your organization's GitHub plan and access controls explicitly provide restricted Pages access. This demonstration contains sample Healthcare-sector information only. Do not add live project, employee, client, security, financial, or protected healthcare information.

## What the demonstration includes

- Weekly Updates and Monthly Reports tabs
- Healthcare sample project information
- Weekly accomplishments, changes, outlook and leadership-support fields
- Monthly condensed-report fields populated from approved weekly updates
- Draft, Sector review and PMO approval workflow states
- Example submission-history tables

This is a visual demonstration. It does not connect to SharePoint, Power Automate, Power BI or production data.
